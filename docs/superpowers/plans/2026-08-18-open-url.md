# Open URL in local browser Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `POST /v1/open-url` endpoint that opens an allowlisted `sentry.io` URL in the local machine's default browser.

**Architecture:** New top-level Ktor module `io.sentry.buddy.openurl`, mirroring the existing `flow` package's model/validator/routes/configure split. A `BrowserLauncher` interface abstracts the actual `java.awt.Desktop` call so routes are testable without popping a real browser.

**Tech Stack:** Kotlin, Ktor (routing, content negotiation, testHost), kotlinx.serialization, `java.awt.Desktop`, `java.net.URI`, kotlin.test.

**Spec:** `docs/superpowers/specs/2026-08-18-open-url-design.md`

## Global Constraints

- Allowlist is domain-only: `scheme == "https"` AND `host == "sentry.io"` exactly (no subdomains, no other hosts, no `http`).
- New module is top-level (`io.sentry.buddy.openurl`), independent of the existing `flow` package.
- Malformed URL / disallowed scheme or host → `400 Bad Request` with `{"error": "<reason>"}`.
- Browser launch failure (headless/unsupported `Desktop`, or `browse` throws) → `500 Internal Server Error` with `{"error": "failed to open url"}`.

package io.sentry.buddy.openurl

import java.net.URI
import java.net.URISyntaxException

private const val ALLOWED_HOST = "sentry.io"

fun validateOpenUrl(url: String): String? {
    val uri = try {
        URI(url)
    } catch (e: URISyntaxException) {
        return "url is malformed"
    }

    if (uri.scheme != "https") return "url must use https"
    if (uri.host != ALLOWED_HOST) return "url host must be $ALLOWED_HOST"

    return null
}
```

package io.sentry.buddy.openurl

import java.awt.Desktop
import java.net.URI

interface BrowserLauncher {
    fun open(uri: URI)
}

class DesktopBrowserLauncher : BrowserLauncher {
    override fun open(uri: URI) {
        check(Desktop.isDesktopSupported() && Desktop.getDesktop().isSupported(Desktop.Action.BROWSE)) {
            "Desktop browse action is not supported on this platform"
        }
        Desktop.getDesktop().browse(uri)
    }
}
```

Create `src/main/kotlin/io/sentry/buddy/openurl/OpenUrlRoutes.kt`:

```kotlin
package io.sentry.buddy.openurl

import io.ktor.http.*
import io.ktor.server.application.*
import io.ktor.server.request.*
import io.ktor.server.response.*
import io.ktor.server.routing.*
import java.net.URI

fun Application.openUrlRoutes(browserLauncher: BrowserLauncher) {
    routing {
        post("/v1/open-url") {
            val request = call.receive<OpenUrlRequest>()

            val validationError = validateOpenUrl(request.url)
            if (validationError != null) {
                call.respond(HttpStatusCode.BadRequest, mapOf("error" to validationError))
                return@post
            }

            try {
                browserLauncher.open(URI(request.url))
                call.respond(HttpStatusCode.OK)
            } catch (e: Exception) {
                call.respond(HttpStatusCode.InternalServerError, mapOf("error" to "failed to open url"))
            }
        }
    }
}
```
